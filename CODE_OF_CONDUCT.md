# Code of Conduct

gitbuddy exists to make git less scary for everyone. Our community should feel the same way.

- **Be kind.** Everyone was a beginner once. There are no stupid questions.
- **Be respectful.** No harassment, insults, or discrimination of any kind.
- **Be helpful.** Explain, don't gatekeep.
- **Assume good intent**, and accept feedback gracefully.

Maintainers may remove comments, issues or contributors that break these rules. To report a problem, contact the maintainer through their GitHub profile.
